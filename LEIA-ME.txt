CHECK-SE — PWA PARA GITHUB PAGES

Este pacote deixa o endereço abaixo com o mesmo visual moderno e o mesmo
comportamento da versão preparada para a Netlify:
https://byskopf.github.io/check-se/

O pacote já está ajustado para o caminho obrigatório /check-se/ e o endereço do
aplicativo Google Apps Script já está configurado no arquivo app.js.

COMO PUBLICAR
1. Baixe e descompacte este arquivo ZIP no computador.
2. Abra o repositório https://github.com/byskopf/check-se na branch main.
3. Clique em Add file e depois em Upload files.
4. Envie TODOS OS ARQUIVOS que estão dentro da pasta descompactada.
5. Confirme a substituição do index.html existente e finalize o commit.
6. Aguarde a publicação do GitHub Pages.
7. Abra https://byskopf.github.io/check-se/ e atualize a página uma vez.

ATENÇÃO
Não envie somente o arquivo ZIP para o repositório. O GitHub Pages não abre os
arquivos que estão dentro do ZIP: ele publica o index.html solto na raiz. Os
arquivos deste pacote precisam ficar diretamente na raiz do repositório.

Os ZIPs antigos que já estão no repositório não impedem o site de funcionar,
mas também não alteram a página publicada.

ARQUIVOS IMPORTANTES
- index.html: nova tela inicial moderna;
- styles.css: visual responsivo;
- app.js: instalação e abertura do CHECK-SE;
- manifest.json: configuração PWA no caminho /check-se/;
- sw.js: cache offline da tela inicial;
- .nojekyll: informa ao GitHub Pages que os arquivos são estáticos;
- ícones PNG e SVG: ícone correto do aplicativo.

ATUALIZAÇÃO DA VERSÃO ANTIGA
O navegador pode manter arquivos antigos por alguns instantes. Depois de
publicar, abra o endereço com internet e atualize uma vez. Se ainda aparecer a
tela antiga, feche a aba, abra novamente e faça uma nova atualização.

OBSERVAÇÃO
O modo offline protege apenas esta tela inicial hospedada no GitHub Pages. O
conteúdo do Google Apps Script pertence a outro endereço e continua usando o
próprio sistema offline do CHECK-SE.
